# skill-review benchmarks

These benchmarks measure **skill-review itself**.

The current fixture, `old-quick-code-review/`, contains an archived review-skill package with confirmed
expected findings and known precision traps.

Benchmarks for other skills should live with those skills and use targets appropriate to what those
skills promise.

Keep fixture bytes immutable, hide expected findings during discovery, and record model, harness,
model reasoning depth, skill effort, time, and worker/main token usage separately.
